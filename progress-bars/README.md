# progress-bars

在 Claude Code 輸入框上方顯示進度條，一眼看到哪些在跑、哪些已完成。

```
● 幫我把登入頁部署上線            ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  72%  12m / ~5m   ×
✓ 任務進度追蹤面板                ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 100%  8m           ×
● Fix upload · localStorage 上傳 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  51%  3m / ~15m    ×
```

## 每一列

- **狀態**：● 執行中、✓ 完成、✗ 失敗或中斷、○ 閒置
- **名稱**：需求的第一行，或其他 session 的「session 名稱 · 目前任務」
- **進度條與百分比**：由 Claude 回報；沒有回報時顯示 `…`
- **時間**：執行中顯示「已用時間 / ~預估剩餘」（例如 `3m / ~25m`），完成後顯示總用時
- **×**：移除這一列。列只會因為按 × 而消失，不會自動清掉

## 列從哪裡來

- **每個需求**：你送出的每個需求自動一列，回合開始時出現、結束時打勾。
- **Claude 的回報**：plugin 提供 `report_progress` 工具，並在系統提示裡要求 Claude 在多步驟工作時用 `id: "current"` 回報百分比與預估時間。並行的工作（子 session、長時間建置）會用自己的 id 另開一列。
- **子代理**：用 Agent 工具開的子代理自動追蹤，結束時打勾。
- **其他 session**（Claude Code Desktop）：每 10 秒讀一次 App 的 session 清單；每個裝了這個 plugin 的 session 都把自己的任務寫進共用的 plugin store，所以所有 session 的進度互相看得到。正在跑、或回報過任務的 session 會列出來。

## 點擊與移除

- 點其他 session 的名稱：由目前這個 session 開出的 session 會直接切過去；其他 session App 不允許程式切換，會跳提示請你從側邊欄點開。
- 在其他 session 那列按 ×：所有 session 都會隱藏它（存在共用 store，重開也一樣）；等那個 session 回報新的進度時再出現。

## 注意

- 百分比與預估時間是 Claude 自己估的，不是量測值。
- 系統提示會多一段說明，Claude 在多步驟工作時會多幾次工具呼叫。
- 子代理沒辦法點擊切換過去（plugin API 沒有這個功能）。
