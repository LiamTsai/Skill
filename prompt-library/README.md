# prompt-library

把送出過的提示詞存起來，存之前可以先編輯，之後也能再改；要用的時候從提示詞庫填回輸入框。

## 存

三種方式都會先打開「存提示詞」面板，你確認或修改名稱、內容後按「存」（在內容欄按 Enter 也是存）才會存：

- 滑鼠移到你送出的訊息上，右上角出現 **☆ 存**。只有你自己送出的訊息才有，背景任務通知、其他 session 的訊息沒有。
- `/save-prompt`：存這個 session 上一則送出的提示詞。
- 提示詞庫裡的 **存目前的草稿**：存輸入框裡還沒送出的內容。

名稱留空就用內容的第一行。

## 用

按輸入框下方、模型選單旁的 **☰ 提示詞**（或打 `/prompts`）打開提示詞庫，最新存的在最上面。

上方的 **搜尋** 欄是模糊比對：名稱或內容裡依序出現這些字就算符合，中間可以夾別的字（`公戰` 找得到「公會戰」）；用空白分開的每個詞都要符合。名稱符合、字連在一起的排前面。

每一則有三個按鈕：

- **填入**：插到輸入框游標的位置，你可以再改，不會直接送出。
- **編輯**：打開同一個面板修改名稱或內容。
- **刪除**：按下後要再按「確定」才會刪。

提示詞所有專案共用，並記下是在哪個專案存的；別的專案存的會在名稱後面標出專案資料夾。按 **全部專案／只看這個專案** 切換。

不會自動刪除或限制筆數，只有你按刪除才會少。

## 存在哪裡

`$.store`：Claude Code 設定資料夾裡這個 plugin 自己的 JSON 檔，只在本機，不會進任何 repo。

## 限制

- 「☆ 存」靠滑鼠移上去才出現；不支援滑鼠懸停的終端機請用 `/save-prompt`。
- Desktop 開新對話時，要送出第一則訊息後才會出現 **☰ 提示詞** 與 **☆ 存**：背後的 Claude Code 程序那時才啟動。
- 手機上不能編輯，也沒有搜尋欄；可以先照原樣存，之後在電腦上編輯。
