# RetroMe

偵測到你在糾正 Claude 時，主動問你要不要「復盤」，並把結論變成 AGENTS.md 或 Skill 的修改建議，你按「套用」才會改檔案。

## 流程

1. **偵測糾正**：你送出訊息時，背景用 haiku 判斷這句是不是在糾正、否定 Claude 剛才做的事（不擋送出，800 字以內、前面有 Claude 回覆的訊息才判斷）。
2. **詢問**：是的話，輸入框上方出現

   ```
   ● 偵測到糾正 「不是這樣，回報前要先自己測過」
   要不要針對這次進行復盤？  [要]  [先不要]
   ```

3. **復盤**：按「要」後用 opus 讀
   - 累積的糾正紀錄（跨 session、跨專案，記錄在哪個專案發生）
   - 最近的對話
   - 全域 `~/.claude/AGENTS.md` 與專案 `AGENTS.md`
   - 全域與專案 `CLAUDE.md`（只當參考，避免提出已經寫過的規則，不會寫入）
   - `~/.claude/skills` 裡的 Skill

   提出最多 3 條建議，顯示在「復盤」面板。
4. **建議**：每條寫明 `[AGENTS.md 規則]`、`[專案 AGENTS.md]` 或 `[Skill: 名稱]`、標題、理由、證據（你說過的原話）與要加到哪個檔的檔尾，附三個按鈕：
   - **預覽改動**：以 diff 顯示要加的內容
   - **套用**：把內容加到該檔檔尾
   - **略過**

## 指令

- `/retro`：手動叫出同一個詢問（用最近一筆糾正）。

## 注意

- 每則符合條件的訊息會多一次 haiku 判斷；按「要」會跑一次 opus。
- 只有按「套用」才會寫檔，且只會加在檔尾，不會改動既有內容。
- 糾正紀錄存在這個 plugin 自己的 store（`~/.claude/plugins/store/`），最多保留最近 50 筆。
- 證據不足時，面板會顯示「這次沒有足夠證據提出修改建議」。
